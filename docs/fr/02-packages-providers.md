# 2. Packages et providers

L’arborescence v2.0 contient packages et providers. Un monorepo de ce type mutualise les contrats d’interface, les clients et les composants de transport entre plusieurs intégrations.

Pour une DApp, il faut identifier le package réellement consommé, sa version et le provider utilisé. La cohérence des versions est aussi importante que la connexion initiale.
