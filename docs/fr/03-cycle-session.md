# 3. Cycle d’une session

Une session WalletConnect organise la relation entre une DApp et un wallet : établissement, propositions de chaînes et de méthodes, demandes de signature puis fermeture ou renouvellement.

L’interface doit rendre visibles les intentions avant signature et gérer les refus, expirations et déconnexions. Une session active ne signifie pas qu’une transaction est automatiquement autorisée.
